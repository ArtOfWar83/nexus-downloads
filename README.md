# Nexus

Nexus is an NDI® management app for the Mac, from Invictus Entertainment, LLC. This page has the Nexus installer, the Nexus Operator Manual and the release notes.

## Get Nexus

- Installer: see Releases (one release per build; the SHA-256 is shown on each release).
- Manual and release notes: the manual/ and release-notes/ folders.
- Plans, pricing and purchase: https://invictusent.com/nexus
